# Changelog

All notable changes are recorded here.

## [0.1.0] - Unreleased

### Added

- Generic port of the author's original session listing, six-check review, Kind 1/Kind 2 decisions, current needs-you list and daily digest.
- Claude Code and both synthetic Codex line shapes, cross-provider review, profiles, scoping, local audit, demo and format diagnostics.
- Eight closed reply templates, one validated owner-decision quote, whole-turn evidence, fixed never-list, explicit send gates, durable accounting and stop controls.
- Bounded overnight observation with visible worker failures and pending work at the deadline.
- Synthetic characterization, privacy and safety regression suites.

### Fixed

- Dry-run watch leaves needs-you state and files unchanged on every local finding. Reviewer replies have a complete validated documentation example and errors name expected keys. Observed worker questions are retained, consent discloses residual personal data, and recognized session IDs avoid card false positives in listings.
- Explicit folder scopes select their single session outside the shell folder; ordinary existing folder components no longer form one opaque value.
- Audit and watch persist the same needs-you entries, show explicit escalation reasons, and preserve the worker's actual question. Consent and timestamp messages and exit precedence are clear.
- Recognized GitHub-style token spans no longer hide an unrelated agent reply; outbound refusal and split-label protection remain in place. Clarified residual personal-data exposure and generated installation artifacts.
- SSN-style IDs, Luhn-valid and grouped card candidates, and IBAN-shaped values are scrubbed; email scrubbing remains enabled by default. Documented personal-data gaps and the actual privacy-refusal remedy.
- Local and live watch share timestamp checks and preserve unchanged privacy refusals. Watch, open and status use the same unresolved-item count.
- Setup recovery for partial Debian virtual environments and actionable scope, ID, config and reviewer errors. Clarified review behavior for unsupported shapes.

### Safety defaults

- Automatic selection off; print-only delivery; both injection adapters disabled.
- Unknown or inconsistent turn evidence flags the human. Agent-written status lines cannot authorize a reply.

Real CLI compatibility, billing and plain-terminal queue behavior still need owner verification. This version is not published on a package index.
